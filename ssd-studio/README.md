# SSD STUDIO — Cinematic Booking Page

An ultra-modern, glassmorphic booking experience for SSD STUDIO built with Next.js, Tailwind CSS, Framer Motion, and React Three Fiber. The hero features an interactive 3D lens with particle dust motes; the overlay delivers a premium booking flow with toggles, floating labels, and animated CTA.

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) to see the page.

## Features

- Dark, cinematic theme with glowing gradients and glassmorphism
- Interactive 3D hero (React Three Fiber + Drei) and floating dust particles
- Text mask reveals, magnetic/glowing CTA, and animated submit state
- Premium booking form with pill toggles, floating labels, custom checkbox, and styled date/time pickers
- Clear contact + disclaimer footer
