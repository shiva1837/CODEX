# CODEX — SSD Studio Landing

Dark, cinematic landing page example for SSD Studio built with **Next.js (App Router)**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **React Three Fiber/Drei**. The page showcases a hero with a glass-like 3D object, a booking form with animated UI, and a contact/footer block.

## Quick start

1. Install dependencies  
   ```bash
   npm install
   # or
   yarn
   ```
2. Run the dev server  
   ```bash
   npm run dev
   # or
   yarn dev
   ```
3. Open http://localhost:3000 to view the site.

## Project structure

- `app/page.tsx` — main page composition (hero, booking, footer)
- `components/` — modular UI sections and 3D canvas
- `app/globals.css` & `tailwind.config.js` — styling, glassmorphism helpers, and theme tweaks

Feel free to fork and adapt this template for your own cinematic landing experiences.
